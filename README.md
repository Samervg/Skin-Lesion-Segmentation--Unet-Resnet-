# Smart Beauty: Skin Lesion Segmentation (Bluesense)

This project is developed for the **Bluesense Smart Beauty** ecosystem. It uses Deep Learning to automatically detect and segment skin lesions (moles and spots) from dermatoscopic images.

## Project Specifications
- **Architecture:** U-Net
- **Backbone:** ResNet34 (Transfer Learning)
- **Accuracy:** 93.43% (Dice Score)
- **Dataset:** HAM10000

## Files in this Repository
- `notebook.ipynb`: The complete training and prediction code.
- `report.pdf`: Detailed project report (Times New Roman, 16pt).
- `deri_lezyon_modeli.pth`: https://drive.google.com/file/d/1DM87FqUCAfWN04XE4lRJ_Eb_BpBFBd31/view?usp=sharing

## How to Run
1. Open the notebook in Google Colab.
2. Upload the `.pth` model file.
3. Run the prediction cells to see the AI in action.
